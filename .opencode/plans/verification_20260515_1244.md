## Hallazgos con Problemas Detectados

### 🔴 NUEVO BUG: `lib/sanitize.ts` contiene byte nulo literal

- **Archivo:** `lib/sanitize.ts`
- **Problema:** El regex en `sanitizeSubject()` contiene un byte null literal (`\x00`) en lugar de la secuencia de escape. Esto hace que git trate el archivo como binario (`Binary files differ`) y `file` lo reporta como `data` en vez de texto.
- **Impacto:** Aunque el build pasa (TypeScript lo tolera), el archivo es invisible para herramientas de texto como grep, diff, y editores que no manejan bytes nulos. Es un bug latente.
- **Línea afectada:** `sanitizeSubject` regex `[\r\n\x00-\x1f\x7f]` — el `\x00` fue escrito como byte literal `0x00` en el archivo.
- **Fix requerido:** Reescribir el archivo con la secuencia de escape correcta: `[\r\n\u0000-\u001f\u007f]`
